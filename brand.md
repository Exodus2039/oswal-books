# Brand — Oswal Books

_Status: set from the product screens and the frontend checklist. Dark only._

Cricket prediction board for Indian fans on mid-range Android phones. English and Hindi.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| background | `#0c1220` | Page |
| surface | `#151c2c` | Cards, chips, nav |
| foreground | `#e8eef8` | Body text |
| muted | `#b7c3d6` | Secondary text |
| border | `#2c3a50` | 1px edges |
| action | `#1aa86a` | The one action on a screen |
| action-foreground | `#042114` | Label on the green action |
| you | `#f2c14a` | Wordmark, WhatsApp join, and the player's own rank |
| mark-foreground | `#1c1404` | Label on the yellow mark |

Cricket identity is a 2px edge, not a recolored card: `#3dbe86`.

## Type

System UI stack, including Noto Sans Devanagari when the phone has it. No webfont download. Body is 16px. Scores and odds use tabular numbers.

## Voice

Short, concrete, match-day. Name the unit (credits). Show the fee, including zero. Say when the score is delayed.

## Do not

No pure black, no blur, no outer glow, no rainbow card themes. Yellow does not replace the green confirm.
